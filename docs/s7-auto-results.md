## 수정한 문제

1. Wazuh API 인증서의 중첩 직접 마운트가 초기 API 볼륨을 이미 초기화된 것으로 오인하게 했습니다. 공식 `/wazuh-config-mount` 복사 경로로 바꾸고 새 볼륨 초기화를 재검증했습니다.
2. n8n 512MiB 제한에서 JS heap 부족으로 종료됐습니다. 제한 768MiB와 Node heap 512MiB로 조정하고 정상·장애 회차를 실행했습니다.
3. 초기 복구 조치와 기존 격리 해제 별칭 `restore`가 충돌했습니다. 개인 완료 조치 `complete_restore`, `complete_quarantine`을 추가하고 API와 대시보드의 활성 조치 판정을 맞췄습니다. 팀 별칭은 보존했습니다.
4. 여러 이전 개인 프로젝트의 정지 컨테이너가 네트워크를 점유했습니다. 정지한 자기 프로젝트 `haedam-s7-auto`만 `down`해 네트워크를 반환하고 새 프로젝트를 기동했습니다. 볼륨을 삭제하거나 전체 prune을 하지 않았습니다.
5. 사용자 요청에 따라 환경값을 공통 JSON·`.env`로 분리했습니다. 에이전트 이름/대상 경로/서비스 주소를 변경하는 회귀 시험과 경로 탈출 거부 시험을 포함해 전체 호스트 테스트 37개, S8/H1/S7 워크플로 생성물 검사, S7 생성 JavaScript 구문 검사가 통과했습니다. 실행 커밋의 staged 비밀 탐지 0건입니다.
