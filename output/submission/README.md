# 제출 ZIP

[김명준 개인 포트폴리오 제출 자료](김명준-개인포트폴리오-제출자료-20261111.zip)는 PPT r7, 제출 안내, 발표·시연·예상 질문, 이력서·자소서 초안, 새 클론 검사, 제출 상태, 해시 목록의 7개 파일을 포함합니다.

11/11 공개 전환·PR #30/#31 병합 후 안내를 갱신했습니다. PPT 자체는 검증된 r7과 바이트가 같습니다. 전체 저장소를 압축하지 않으므로 로컬 환경 파일·인증서·쿠키·가상환경은 포함하지 않습니다. 문서의 상대 링크는 공개 GitHub `main` 링크로 바꿉니다.

저장소 루트에서 Python 3.12 표준 라이브러리로 다시 만들 수 있습니다. 이 명령은 해당 ZIP만 갱신하며 업로드·병합·서비스 실행을 하지 않습니다.

```powershell
py -3.12 tools/package_submission.py --ppt 'output/portfolio/김명준-해담시청-SOAR-개인포트폴리오-20261111-r7.pptx' --output 'output/submission/김명준-개인포트폴리오-제출자료-20261111.zip' --ref main
```

`manifest.json`의 SHA-256은 각 포함 파일의 무결성을 확인하기 위한 값입니다. `--ref`는 문서 링크의 브랜치/커밋을 선택하며 해당 코드가 실제 배포·실측되었다는 판정을 만들지 않습니다.
